Dagens datum:

Min arbetsprocess

  1. Läs igenom uppgiften
    • Jag började med att läsa igenom uppgiften samt teori & läsanvisningar och eftersom svenska inte är mitt modersmål brukar jag försöka gå igenom uppgiften med min sambo för att va säker att jag har förstått rätt.
  2. Börja bygga grundstrukturen
    • Efter jag följde videon och hade mina tomma sidor redo började jag bygga ihop grundstrukturen för mina sidor.
    • På tiktok hade jag hittat ett konto som lägger upp ideer för olika färg kombinationer. Jag hittade några jag gillade och ville testa hur de fungerade med en enkel webbsida.
    • Efter grunden va klar läste jag upp om vite för att lägga in mina bilder korrekt och efter väldigt mycket om och men så fungerade det.
    • Därefter försökte jag ladda upp i Git via visual studios men då gick väldigt mycket fel. Fram tills dess har jag bara sparat lokalt eftersom jag inte hade gjort så mycket. Men under tiden det tog mig för att komma igång med NodeJs och parcel, bygga ihop grunden, headern och footern, och lägga in bilderna så krashade min dator. När den började igen så märkte jag att det va väldigt mycket konstigt med min dator och det tog en hel dag att hitta problemet, lösa det, och sen märka att jag måste börja om helt (Onedrive problem, inte Github som jag trodde då). Dagen efter började jag bygga upp allting igen och istället för att då lösa varför Git och jag inte kom så bra överens så ville jag fortsätta med uppgiften utan Git.
  3. Börja...igen
    • Efter jag hade börjat om så kunde jag äntligen gå vidare med detaljerna. Jag är osäker vad som inspirerade mitt meny val, men jag ville försöka ha en väldigt enkel meny som bara innehåller ikoner. Jag visste att den skulle behöva vara sticky och då ville jag ha den längst ner. Medans jag fösökte få det att fungera tänkte jag att det inte riktigt passar med större skärmar men istället för att göra en helt annorlunda meny, la jag bara in etiketter så det skulle va tydligare.
    • När jag hade en header, footer, meny på alla sidor samt bilderna jag ville ha på bildsidan kände jag att det bara va att göra hemsidan responsiv och sen va klar men då kom jag på att jag har inte gjort nånting men javascript. Jag ville inte börja om med någon av delarna igen och visste inte vad jag skulle använda javascript för och tänkte att en enkel klocka och datum som uppdateras med sidan får duga just nu och om jag hittar på något roligare så lägger jag in det också.
  4. Responsiv
    • För att göra webbsidan responsiv hade jag inte för mycket att ändra mer än att lägga in etiketter till menyn, ändra om layouten till bilderna och justera text storlek.
  5. Automatisering
    • För att automatisera min webbsida har jag använt Vite samt ett Node.js-script för bildoptimering.
    • Minifiering av CSS och JavaScript - När jag kör npm run build skapar Vite en produktionsbuild där CSS och JavaScript optimeras och minifieras automatiskt.
    • Optimering av bilder - Jag sparar originalbilder i mappen image-src. Med hjälp av ett script (Sharp) genereras optimerade versioner i mappen image i formaten JPG (komprimerad fallback), WebP och AVIF.
  6. Publicering
    • För att publicera har jag valt att använda Netlify genom att koppla min github repo till den.
    • Innan jag använder bygg kommandot i terminalen sparar jag alla mina filer ifall min dator väljer att tappa bort allting igen.
    • När Jag har dubbelkollat igenom allting och läst igenom uppgiften några extra gånger så känner jag att webbsidan är klar och bygger ihop den.
    • Efter webbsidan skapades märkte jag att den inte visade ikonerna eller mina bilder så efter jag lyckades med bilderna kunde jag inte få ikonerna att fungera så jag tar bort dem helt och har en meny med bara text.
